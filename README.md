# A 股投研平台

本地运行的迷你投研平台，只做三件事：**数据、因子、回测**。

目标是把「有个想法 → 看到结果」的时间从一周压到一小时。

## 快速开始

```bash
# 1. 同步基础数据（交易日历、股票列表）
python scripts/sync_basic.py

# 2. 同步行情与复权因子（首次约 1 小时，支持断点续跑）
python scripts/sync_prices.py --universe hs300 --start 2020-01-01

# 3. 数据质量校验
python scripts/check_data.py

# 4. 计算因子
python scripts/compute_factors.py
python scripts/compute_factors.py --factors momentum_20d   # 只算一个

# 5. 因子分组回测
python scripts/run_group_backtest.py --factor momentum_20d --horizon 20 --groups 5

# 6. 控制变量后的因子有效性
python scripts/run_neutralized_backtest.py --factor momentum_20d --layer volatility_20d
```

## 现在能回答的问题

**某个价格类因子有没有预测力？**
`run_group_backtest.py` 把股票按因子值分五组，看各组未来 N 日收益是否单调、多空组合能赚多少。

**这个因子的作用是不是假象？**
`run_neutralized_backtest.py` 先按另一个变量分层，再在层内检验。用来排除「因子只是某个混淆变量的马甲」。

**换个持有期、换个分组数会怎样？**
`--horizon 5` / `--horizon 60` / `--groups 10`，参数化了，不用改代码。

**加一个新因子要多少工作量？**
写一个函数、一行 `register`、在 `factors/__init__.py` 加一行导入。引擎、表结构、测试都不用动。

## 已有结论（沪深 300，2020-04 ~ 2026-09，79 个调仓期）

| 因子 | 多空年化 | 夏普 | 结论 |
|---|---|---|---|
| 20 日动量 | -1.51% | -0.06 | 整体无效，分组呈 U 型 |
| 20 日反转 | +0.95% | 0.04 | 整体无效 |
| 20 日波动率 | +16.82% | 0.57 | 有效，高波动组跑赢 |

动量的 U 型经波动率中性化后消失，确认是混淆。但中波动层出现了显著反转（多空 -11.68%，严格单调），尚未做稳健性检验。

## 已知限制

1. **样本只覆盖沪深 300**，全是大盘股，结论不能外推到全市场。
2. **退市股缺失**（库里只有 5576 只在市股票），长期回测存在幸存者偏差。
3. **`dim_stock.list_date` 为空**，新股判断用「前 5 个交易日」近似。
4. **未处理交易成本**，所有多空收益都是理论值。
5. 样本 6 年半、79 个调仓期，统计效力有限。

## 几条硬约束

1. 库中只存不复权价 + 复权因子，**永不存前复权价**。
2. 财务数据必须带公告日，查询默认只看已公告数据。
3. 所有跨除权日的收益率计算，必须先复权。
4. 股票代码统一格式（`600000.SH`）。
5. 任何依赖外部会话状态的标志位，都要设计成可失效、可重建。
