# A 股投研平台

本地运行的迷你投研平台，只做三件事：**数据、因子、回测**。

目标是把「有个想法 → 看到结果」的时间从一周压到一小时。

## 快速开始

```bash
# 0. 初始化表结构（幂等，新增表后重跑一次）
python scripts/init_db.py

# 1. 同步基础数据（交易日历、股票列表）
python scripts/sync_basic.py

# 2. 同步行情与复权因子（首次约 1 小时，支持断点续跑）
python scripts/sync_prices.py --universe hs300 --start 2020-01-01

# 3. 数据质量校验
python scripts/check_data.py

# 4. 计算因子
python scripts/compute_factors.py
python scripts/compute_factors.py --factors momentum_20d   # 只算一个

# 5. 因子分组回测
python scripts/run_group_backtest.py --factor momentum_20d --horizon 20 --groups 5

# 6. 控制变量后的因子有效性
python scripts/run_neutralized_backtest.py --factor momentum_20d --layer volatility_20d

# 7. 组合回测（含交易成本，自动存档）
python scripts/run_backtest.py --factor momentum_20d

# 8. 因子快照（因子库页面的数据源；需先停掉界面，库文件是独占锁）
python scripts/compute_factor_reports.py
python scripts/compute_factor_reports.py --factor roe --force   # 只算一个、忽略指纹
```

## 现在能回答的问题

**某个价格类因子有没有预测力？**
`run_group_backtest.py` 把股票按因子值分五组，看各组未来 N 日收益是否单调、多空组合能赚多少。

**这个因子的作用是不是假象？**
`run_neutralized_backtest.py` 先按另一个变量分层，再在层内检验。用来排除「因子只是某个混淆变量的马甲」。

**这个因子的预测力有多强、多稳？**
`run_ic.py` 每期算因子排名与未来收益排名的秩相关，输出 IC 均值、ICIR、胜率、t 值和衰减曲线。分组法看「平均赚不赚」，IC 看「是不是每期都赚」。

**换个持有期、换个分组数会怎样？**
命令行仍支持 `--horizon 5` / `--groups 10` 做临时探索；但因子库里的档案只按**因子自己声明的
参数**算（写在因子文件里的 `horizon` / `groups`）。参数一变就是另一份档案，旧的不被覆盖。

**加一个新因子要多少工作量？**
写一个函数、一行 `register`、在 `factors/__init__.py` 加一行导入。引擎、表结构、测试都不用动。

## 已有结论（沪深 300，2020-04 ~ 2026-09，79 个调仓期，扣双边成本）

| 因子 | 多空年化 | 夏普 | 多头年化 | IC 均值 | t 值 | 结论 |
|---|---|---|---|---|---|---|
| 20 日动量 | -11.16% | -0.46 | 17.26% | -0.0251 | -1.08 | 无效，分组呈 U 型 |
| 20 日反转 | -8.98% | -0.37 | 18.88% | +0.0251 | +1.08 | 无效 |
| 20 日波动率 | +7.68% | 0.26 | 24.72% | -0.0282 | -0.94 | 分组有效但 IC 为负，不稳定 |
| ROE | -8.00% | -0.50 | 12.52% | -0.0091 | -0.56 | 无效 |
| 净利润同比 | -0.32% | -0.02 | 16.37% | -0.0106 | -0.51 | 无效 |

五个因子的 t 值绝对值均小于 2，**统计上都不显著**。同期池内等权基准年化 18.74%。

动量的 U 型经波动率中性化后消失，确认是混淆。但中波动层出现了显著反转（多空 -11.68%，严格单调），尚未做稳健性检验。

波动率因子存在 IC 与分组收益方向相反的现象：分组显示高波动跑赢，IC 显示多数期数高波动跑输（胜率 43%），少数几期大幅跑赢拉高了均值。分年度看 IC 符号反复（2020 +0.10、2023 -0.11、2025 +0.11、2026 -0.15），说明这个因子收益依赖少数行情。

## 已知限制

1. **样本只覆盖沪深 300**，全是大盘股，结论不能外推到全市场。
2. **退市股缺失**（库里只有 5576 只在市股票），长期回测存在幸存者偏差。
3. **`dim_stock.list_date` 为空**，新股判断用「前 5 个交易日」近似。
4. **已计交易成本**（买入 0.13%、卖出 0.23%），但未模拟涨停与停牌不可成交，当作可执行策略仍会高估收益。
5. 样本 6 年半、79 个调仓期，统计效力有限，五个因子的 t 值均不显著。
6. **分组收益与 IC 可能矛盾**（已见于波动率因子）：前者平均收益，后者平均相关性，判断因子稳定性必须两个都看。
7. **因子页与策略页数字不完全一致**：前者用 `pct_rank` 上取整分组、旧成本口径，后者用分位卡阈值、逐笔台账。同名指标差 4~5pp 属正常，不要当 bug 修。

## 几条硬约束

1. 库中只存不复权价 + 复权因子，**永不存前复权价**。
2. 财务数据必须带公告日，查询默认只看已公告数据。
3. 所有跨除权日的收益率计算，必须先复权。
4. 股票代码统一格式（`600000.SH`）。
5. 任何依赖外部会话状态的标志位，都要设计成可失效、可重建。
