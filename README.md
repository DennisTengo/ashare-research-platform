# A 股投研平台

本地运行的迷你投研平台，只做三件事：**数据、因子、回测**。

目标是把「有个想法 → 看到结果」的时间从一周压到一小时。

## 它是什么 / 不是什么

**是**：一个可以自己掌控数据、结果可复现、每行代码都能解释的研究基础设施。

**不是**：聚宽的替代品。没有分钟数据、没有实盘、没有社区、没有多用户。

明确不做的事见 `docs/requirements.md` 第 1.4 节。

## 目录

| 目录 | 职责 |
|---|---|
| `collector/` | 抓取，只负责取回并落地原始数据 |
| `staging/` | 原始 parquet，只增不改 |
| `cleaner/` | 清洗、标准化、异常标记 |
| `warehouse/` | 入库 DuckDB |
| `factor/` | 因子定义（新增因子只动这里） |
| `strategy/` | 策略定义 |
| `backtest/` | 成交、成本、绩效 |
| `app/` | Streamlit 页面 |
| `common/` | 配置、日志、连接、日历工具 |
| `tests/` | 单元测试 |

## 几条硬约束

1. 库中只存不复权价 + 复权因子，**永不存前复权价**。
2. 财务数据必须带公告日，查询默认只看已公告数据。
3. 原始层（`staging/`）数据只增不改。
4. 股票代码统一格式（`600000.SH`）。
